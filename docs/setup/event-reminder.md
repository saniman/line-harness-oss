# イベント当日リマインドの運用手順

イベントの申込確定者（`status = 'confirmed'`）へ、当日の決まった時刻に LINE でリマインドを送る機能（Issue #67）。

> 送信日時を空欄にしておけば何も送られない。既存イベントの挙動は変わらない。

## 使い方

管理画面のイベント作成／編集フォームで、次の2項目を入れるだけ。

| 項目 | 意味 |
|---|---|
| **当日リマインドの送信日時** | この時刻を過ぎた最初の cron（5分毎）で配信される。**空欄なら送らない** |
| **当日リマインドの本文** | 会場・地図URL・持ち物・事前確認などを自由文で書く |

イベント名と開始時刻は**自動で入る**ので、本文には書かなくてよい。

### 本文の例

```
📍【会場名】レンタルスペース Eir
https://maps.app.goo.gl/57Tq8qAjKKmows1r8
💻 ノートパソコン・電源アダプタをお忘れなく

【事前確認】
以下3つがパソコンに入っているかご確認ください。
・Claude Desktop
・Node.js（LTS版）
・Git

入っていない方も大丈夫です。会場でご案内します。
状況だけスタンプで教えていただけると助かります！

✅ 準備OK
🙋 まだ／わからない
```

### 実際に届くメッセージ

```
📢 本日のイベントリマインドです

「沖縄AI活用セミナー」
⏰ 開始 19:00

📍【会場名】レンタルスペース Eir
https://maps.app.goo.gl/57Tq8qAjKKmows1r8
💻 ノートパソコン・電源アダプタをお忘れなく
...
```

- 見出しは**送信日と開催日の JST 暦日差**で変わる：当日 → `本日の`、前日 → `明日の`、それ以外 → 見出しに日付は付かず開始時刻に日付が入る（`⏰ 開始 09/13(日) 19:00`）
- 前日に送る設定にしても「本日」と書かれないので、送信日時を自由に決めてよい

## なぜ Flex ではなくテキストなのか

**Flex の text コンポーネントは URL を自動リンクしない。** 地図URLをタップ可能にするには
uri アクションのボタンにする必要があり、「自由文の中に URL を混ぜる」この形式と両立しない。
プレーンテキストなら LINE クライアントが自動でリンク化する。

## 配信の条件

すべて満たした申込にだけ届く。

- 申込が `status = 'confirmed'`（`pending` = 決済途中／`cancelled` は対象外）
- その申込にまだリマインドを送っていない（`event_bookings.reminder_sent_at` が NULL）
- イベントに送信日時が入っている（`events.reminder_at` が NULL でない）
- 送信日時を過ぎている
- **イベントがまだ終わっていない**（`end_at` を過ぎたら送らない）
- 友だちが公式アカウントをブロックしていない（`friends.is_following = 1`）

補足：

- 同じ人が同じイベントに2件申し込んでいても **1通だけ**送る
- 送信日時を過ぎたあとに新しく確定した申込には、次の cron で届く（当日の駆け込み申込にも案内が届く）
- **非公開（`is_published = 0`）でも送る**。満席になったイベントを一覧から隠すために非公開へ戻す運用があり、
  そこで参加者のリマインドが黙って止まると「申込は成立しているのに案内が来ない」事故になるため

## ⚠️ LINE の月間メッセージ通数

リマインドは**参加者の人数ぶん**通数を消費する（20人なら20通）。
無料のコミュニケーションプランは **200通/月・追加購入不可**。
申込完了通知・運営者通知も同じ枠から出ていくので、イベントを重ねると枯渇しうる。

枯渇すると push が 4xx を返し、リマインドだけでなく**申込者への完了通知も落ちる**。
どちらもベストエフォート（catch して console.error）なので、
**LINE Official Account Manager か Workers Logs を見ないと気づけない**。

## トラブルシュート

| 症状 | 原因 | 対処 |
|------|------|------|
| 誰にも届かない | 送信日時が空欄 | 管理画面で送信日時を入れる |
| 誰にも届かない | 送信日時がイベント終了後 | `end_at` より前の時刻に直す |
| 一部の人に届かない | その人が友だちをやめている | 仕様（`is_following = 0` には送らない） |
| 一部の人に届かない | 申込が `pending` のまま | 決済が完了していない。参加者一覧で確認する |
| 届かない | 月間通数の枯渇 | LINE Official Account Manager で当月の利用通数を確認する |
| 原因が分からない | — | Cloudflare ダッシュボード → Workers → line-harness → Logs で `[event-reminders]` を探す |
| まれに2通届いた | 送信直後の異常終了 | 仕様（at-least-once）。「送ってから記録」なので、記録前に落ちると再送される |

## 実装の場所

- 配信ロジック: `apps/worker/src/services/event-reminders.ts`
- cron への登録: `apps/worker/src/index.ts`（`*/5 * * * *` レーン）
- 管理画面: `apps/web/src/app/events/page.tsx`（作成）/ `apps/web/src/app/events/detail/event-detail-client.tsx`（編集）
- DB: `packages/db/migrations/825_event_reminders.sql`
